# NutriCart

DECO3500 Social & Mobile Computing · Semester 2, 2026 · Team 25

NutriCart Hub is a shared food system for student share houses that consists of a detachable Cart Unit that travels to the grocery store with your shared list, budget, and price comparison, as well as a Home Dock in the kitchen for planning. The full explanation is in the [Design Process Overview](https://github.com/Anujithaaa/DECO3500-Team25-NutriCart/wiki/Design-Process-Overview).
