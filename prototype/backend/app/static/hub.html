Connection details

Phone setup: run the backend on this computer using python run.py. Put this computer's LAN address into cart-expo/.env, for example EXPO_PUBLIC_API_URL=http://192.168.1.20:8000. The phone and computer should be on the same Wi‑Fi for the simplest setup.
